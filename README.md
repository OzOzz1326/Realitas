# REALITAS - Projeto de fã
Realitas é um projeto de estudo de fã de Ordem Paranormal, de uso pessoal e sem fins lucrativos, com o objetivo de suprir faltas e problemas de outros aplicativos e sites de RPG para players.

Para esse projeto está sendo usado umas IAs, como a do VScode e do Antigravity, mas com correções e partes feitas a mão.
